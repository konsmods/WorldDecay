title=World Decay [B42] [Playtest]
description=Transforms Knox County into a decaying post-apocalyptic wasteland. When each map chunk loads, the mod runs its generators procedurally: vegetation (trees, bushes, grass, vines), structural decay (cracks, burnt walls, broken doors and windows, bent fences), trash and barricades.
description=
description=It keeps a persistent chunk cache to skip already visited areas and a batched dispatcher to avoid lag spikes. It includes cleaning tools and full sandbox control over every element.
description=
description=[h1]Key Features[/h1]
description=[list]
description=[*]Vegetation system - trees, bushes, grass and vines with configurable percentages via sandbox
description=[*]Urban decay - cracked roads, burnt walls, broken doors and windows, bent and broken fences
description=[*]Barricades - leftover barricades from people who held out and lost, scattered across the map
description=[*]Trash and debris - piled-up garbage left behind by years of abandonment
description=[*]Vehicle deterioration - rust, blood stains, damaged/missing parts
description=[*]Roof destruction on upper floors
description=[*]Indoor overgrowth
description=[*]Cleaning system - right-click menu to remove vegetation and clear areas for rebuilding
description=[*]World Age Scaling - decay increases as the world gets older
description=[*]Incremental Re-Decay - already explored areas continue to decay over time
description=[*]Seasonal vegetation - trees grow a seasonal foliage crown, bushes bloom, grass dries in autumn/winter, and vines cycle through growth/dieback frames, updating live as seasons/snow change
description=[*]Full sandbox customization - every element can be tuned, enabled or disabled
description=[/list]
description=
description=[b]Includes:[/b]
description=[list]
description=[*]World Decay (core mod)
description=[*]Manik's A Decade Later texture submod (optional - retextures vanilla tiles with a decayed look)
description=[*]WorldDecay_VehicleRetexture submod (optional - rust and moss retexture skins for KI5 vehicles)
description=[/list]
description=
description=[h1]Performance Notice[/h1]
description=This mod changes world generation heavily and adds a large number of objects to every loaded chunk. As a result, it may negatively impact performance on lower-end systems. This is expected given how Project Zomboid handles object rendering.
description=
description=First load: You may notice some lag during the first few seconds after loading in, while the mod generates vegetation and objects across all visible chunks. Performance stabilizes once the first pass completes.
description=
description=[b]Recommendations:[/b] Allocate more RAM to the game if you can. Lower vegetation percentages in sandbox options if you experience lag. In multiplayer, host and server specs matter a lot.
description=
description=[h1]Load Order[/h1]
description=Place this mod as close to the TOP of your load order as possible. If other mods overwrite the same world tiles, the load order decides which one wins.
description=
