[h1]2.1.0[/h1]
[list]
[*]Trees, bushes, grass, and vines now use vanilla's real seasonal sprite data (reverse-engineered from vanilla's own erosion system) instead of a static random sprite pool.
[*]Trees grow a seasonal foliage crown (attached on top of the trunk, so chopping still only takes one hit) and drop it in winter; evergreen species are unaffected. Both trees and bushes swap to a snow-dusted frame while it's snowing.
[*]Bushes now bloom flowers during their real vanilla bloom window and lose their seasonal foliage/flowers in winter.
[*]Grass objects (the ones with visible depth, not the ground overlay) now dry out to vanilla's yellowed autumn/winter look instead of staying green year-round.
[*]Vines now cycle through vanilla's real growth/regrowth/dieback frames across the seasons instead of always using the peak-growth look.
[*]Already-placed trees, bushes, grass, and vines now update live as the season changes or snow starts/stops, instead of only reflecting whatever season they happened to be placed in.
[*]Fixed vines never actually being detected/tagged as WorldDecay-placed: vine sprites are applied as an overlay on the host wall/fence in vanilla's own tile data rather than as a standalone object, so the old tagging check could never see them.
[*]Added debug tools (debug mode only): Advance Month, Print Climate Info, Force Reseason Nearby Trees/Bushes/Grass/Vines, and a Spawn Tree submenu for previewing every vanilla tree species/tier/season combination on demand.
[/list]

[h1]2.0.2[/h1]
[list]
[*]Fixed fence generator crash spam: isEntityObject() used obj:getClass():getSimpleName(), which Kahlua can't reflect as an indexable table in B42, throwing a RuntimeException on every fence-bearing square. Now uses instanceof(obj, "IsoEntity").
[*]Stopped vines spawning on squares containing construction_* objects (scaffolding/construction objects).
[/list]

[*]Added sprite exception for low house walls (walls_exterior_house_low_*) to force short vines only.
[*]Fixed wall/fence vines overshooting their host wall height.
[*]Fixed modlist errors: server-only debug require and unescaped % in sandbox strings.
[*]Fixed vehicle brake/suspension removal leaving tire attached; retuned defaults.
[*]Fixed grass overlay depth cutoffs, added real grass objects outdoors.
